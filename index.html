The problem is not the fall itself but the time an older adult lies undiscovered after it 해결하려는 문제는 낙상 자체가 아니라, 낙상 후 발견이 늦어져 생기는 방치 시간

  • A smartphone mounted on a walker, wheelchair, or indoor stand watches the user through its camera, with no button to press and nothing to wear 보행기·휠체어·실내 거치대에 장착한 스마트폰 카메라로 감지하므로 버튼을 누르거나 기기를 착용할 필요가 없음
  • Connects the whole first response in one service: fall candidate detected → wellness check ("Are you okay?") → guardian alert, escalating to a 119 call if needed [낙상 후보 감지 → 안부 확인("괜찮으세요?") → 보호자 알림]을 하나의 서비스로 연결하고, 필요하면 119 신고로 이어짐
  • User responses and guardian confirmations are stored as false-positive / false-negative feedback to keep tuning the detection threshold 어르신의 응답과 보호자 확인 결과를 오탐·미탐 피드백으로 축적해 감지 임계값과 성능을 지속 개선

MediCart: Intelligent Hospital Nursing Assistant Robot MediCart: 병원 지능형 간호사 보조 로봇

  • Designed to reduce nurses' repetitive mobility tasks so they can focus on core patient care 간호사의 반복·이동 업무를 자동화해 핵심 케어에 집중할 수 있도록 개발
  • Mode A: autonomously patrols wards, verifies patient identity via QR wristband, and assists with digital intake forms 모드 A: 병실을 자율 순찰하며 QR 팔찌로 환자 신원을 확인하고 웹 문진을 보조
  • Mode B: follows the nurse to each room and cross-validates medication labels against prescriptions via OCR, preventing administration errors at the point of care 모드 B: 간호사를 추종하며 약품 라벨을 OCR로 처방전과 비교 검증해 투약 오류를 예방

Operating Modes 운영 모드

Mode A

Autonomous Patrol & Interview Assist: Robot navigates ward waypoints, confirms patient presence (YOLOv8s), scans QR wristband, validates room assignment via DB, then waits for web intake form submission. 자율 순찰 + 문진 보조: Nav2 웨이포인트로 병실 순회, YOLOv8s 재실 확인, QR 팔찌 스캔, DB 병실 검증 후 웹 문진 완료 대기.

Mode B

Nurse-Following Medication Assist: Robot follows the nurse (OAK-D depth + ReID tracking), parks at each room, then sequentially verifies each medication label via GCP Vision OCR against the prescription order. 간호사 추종 + 투약 보조: OAK-D depth + ReID로 간호사 추종, 각 병실 도착 후 GCP Vision OCR로 약품 라벨을 처방 순서대로 순차 검증.

A Doosan M0609 6-axis collaborative robot that fully automates pancake production across 6 sequential steps: dough placement (tong), pressing, plate setting, flipping (spatula), sauce, and powder topping. The system features 5-tool automatic exchange, force/compliance control, spline path planning, and a Firebase-backed web interface for remote control and real-time monitoring, including a customer-facing kiosk with TTS voice guidance. Node Architecture & Safety 노드 구조 및 안전

2-Node 4-Thread 2노드 4스레드
  • Task node: Main thread polls Firebase commands, Robot Task thread dispatches motion 태스크 노드: Main 스레드는 Firebase 폴링, Robot Task 스레드는 모션 디스패치
  • Control node: Control Spin thread keeps ROS comms always-on, Status Polling thread polls GetRobotState every 0.5s 제어 노드: Control Spin 스레드는 항시 ROS 통신 유지, Status Polling 스레드는 0.5초 간격으로 GetRobotState 폴링
  • Uses 1:1 acknowledged service calls instead of fire-and-forget topics; if no response arrives, immediately triggers safe stop 토픽 대신 1:1 확답 서비스 호출 사용, 응답 없으면 즉시 안전 정지

Undergraduate capstone research designing a 3-DOF collaborative robot arm driven by water-hydraulic EHA (Electro-Hydraulic Actuators) to achieve a payload-to-weight (P/W) ratio exceeding 1.0, a benchmark no commercially available cobot currently meets 수압 EHA(전기 유압 액추에이터)로 구동하는 3자유도 협동로봇 팔을 설계하여, 현재 상용 협동로봇 중 달성한 기기가 없는 P/W(가반하중/자체중량) 1 이상을 목표로 한 졸업 논문

  • The arm (AL6061, 13.96 kg) lifts 20 kg payloads, yielding P/W = 1.43, 3–8× higher than UR20 (0.31) and LBR iiwa (0.47) AL6061 재질 로봇팔(13.96 kg)로 20 kg 가반하중을 실현해 P/W = 1.43 달성. UR20(0.31), LBR iiwa(0.47) 대비 3~8배 높은 수치
  • Also built an ANN model that instantly estimates cylinder pressure without iterative inverse kinematics calculation 역기구학 반복 계산 없이 실린더 압력을 즉시 추정하는 ANN 모델도 구성

Research Motivation 연구 배경

  • Commercial cobots average only 6.3 kg payload and all have P/W < 1, meaning they weigh more than they can carry 상용 협동로봇 평균 가반하중은 6.3 kg에 불과하고, P/W도 모두 1 미만(로봇 자체 무게가 가반하중보다 큼)
  • Heavy logistics tasks (20 kg+ parcels, waste sorting) still require large equipment like forklifts and hoists 20 kg 이상 택배 분류, 생활계 폐기물 처리 등 고하중 작업에는 지게차·호이스트 등 대형 장비가 필요
  • EHA-driven linear actuation to achieve both high payload and a compact, safe form factor for human collaboration is the starting point of this research EHA 선형 구동으로 고가반하중과 경량·안전 형태를 동시에 달성하는 것이 본 연구의 출발점

Robot Design 로봇 설계
  • 3-DOF arm, AL6061, 13.96 kg self-weight, 20 kg payload → P/W = 1.43 3자유도 팔, AL6061, 자체중량 13.96 kg, 가반하중 20 kg → P/W = 1.43
  • Cylinder 2 max pressure: 2,111 N / 6.72 MPa (drives Link 2, mounted 50 mm from its end) 실린더 2 최대 압력: 2,111 N / 6.72 MPa (링크 2 구동, 링크 2 끝에서 50 mm 지점에 설치)

ANN IK Model
  • 100-point workspace dataset (80:20 split), 1 hidden layer × 10 neurons, Adam optimizer, MSE loss, ReLU + Linear activation, early stopping at 222 epochs 작업공간 100개 데이터셋(8:2 분할), 은닉층 1 × 뉴런 10, Adam 옵티마이저, MSE 손실, ReLU + Linear 활성화, 222에폭 early stopping

Automatic Conveyor Belt System with Ultrasonic Sensor Arduino Uno와 초음파 센서를 활용한 자동 컨베이어벨트 시스템

A self-regulating conveyor belt system that automatically starts and stops based on object presence 초음파 센서로 물체 유무를 감지해 컨베이어벨트를 자동으로 작동·정지하는 시스템

  • An HC-SR04 ultrasonic sensor continuously measures the distance above the belt HC-SR04 센서가 벨트 위 거리를 지속 측정
  • When an object is detected within 15 cm, the belt activates via a stepper motor and pulley mechanism 15 cm 이내로 물체가 감지될 시 스텝모터·풀리 기구를 통해 동작
  • When the belt is clear, the motor stops automatically, eliminating the need for manual power control 벨트 위에 물체가 없으면 자동 정지되어 수동 전원 조작이 불필요

System Logic 동작 로직

Ultrasonic Sensing초음파 거리 측정 → Distance < 15 cm?15 cm 이내 감지? → Stepper Motor ON / OFF스텝모터 작동 / 정지 → Conveyor Belt Runs / Stops벨트 가동 / 자동 정지

  • Speed adjustment possible without changing the stepper drive code 스텝 드라이브 코드 변경 없이 속도 조정 가능
